# Storefront Route Group (`app/(storefront)`)

## Overview
Customer-facing Next.js App Router route hierarchy for the VÉRONA fashion boutique.

## Sub-routes (Planned for Phase 02+)
- `/`: Editorial Homepage & Featured Collections
- `/category/[...slug]`: Category Listing & Faceted Filter Grid
- `/product/[slug]`: Product Detail Page (PDP)
- `/cart`: Bag & Review
- `/checkout`: Multi-step Checkout
- `/account`: Customer Profile, Saved Addresses & Orders

## Rule
No Phase 02 routes are implemented during Phase 01.

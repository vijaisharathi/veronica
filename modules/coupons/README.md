# Coupons & Promotions Domain (`modules/coupons`)

## Overview
Discount rule engine, voucher code redemption, cart-level offers, and referral incentives.

## Roadmap Phase
**Phase 16 — Coupons, Vouchers & Promotional Engine**

## Key Responsibilities
- Percentage, fixed amount, and BOGO (Buy One Get One) discount calculations.
- Coupon usage limits (per customer, per order, global limits).
- Category and minimum order value validation rules.

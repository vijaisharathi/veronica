# Returns & Exchanges Domain (`modules/returns`)

## Overview
Customer return requests, size exchanges, reverse logistics pickup scheduling, and quality check (QC) processing.

## Roadmap Phase
**Phase 14 — Returns, Exchanges & Reverse Logistics**

## Key Responsibilities
- Return policy rule engine (category-specific return windows, non-returnable items).
- Reverse pickup generation and courier assignment.
- Warehouse quality inspection status transitions and automated refund triggers.

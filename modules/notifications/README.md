# Notifications Domain (`modules/notifications`)

## Overview
Multi-channel transaction and marketing communications (Email, SMS, WhatsApp, Web Push).

## Roadmap Phase
**Phase 18 — Multi-channel Notification Engine**

## Key Responsibilities
- Transactional messages (order confirmation, dispatch alerts, OTP, delivery notifications).
- Abandoned cart recovery alerts and back-in-stock notifications.
- Notification dispatch retry mechanisms and delivery webhook ingestion.
